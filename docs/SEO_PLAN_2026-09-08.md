- 地圖結果：單獨追蹤合法商家檔案的曝光與網站點擊，不混算為本站自然搜尋前十名。
- 付費搜尋：若需要較快爭取 `SUZUKI` 搜尋版位，可另外規劃 Google Ads；廣告是否出現及位置仍依競價與廣告評級決定，不會保證首頁常駐。[Google Ads 廣告評級](https://support.google.com/google-ads/answer/1722122?hl=zh-Hant)
- 商業成效：自然搜尋帶來的有效購車諮詢與試乘預約。LINE／電話點擊是意向事件，不等於收到案件或成交。

## 地區信任與站外曝光

Google 商家規範明列：企業的業務人員與客戶開發專員不符合個人專業執業人員檔案資格。因此不能直接按舊營運筆記替汽車業務另開一個商家檔案；應由有權限的人維護真實北投據點，且只有在該網站適合代表據點並獲授權時才安排網站連結。[Google 商家資格](https://support.google.com/business/answer/3038177?hl=zh-Hant)

- 顧問個人曝光以本站、實際經營的社群與經銷商顧問介紹為主；可爭取經銷商官方顧問頁提供相關連結，本次不對外聯絡。
- 合法據點檔案維持真實店名、地址、電話、營業時間與現場照片；個人電話與據點電話各自標明，不為一致性而混用。
- 分享具有使用價值的試乘／選車內容；使用獲准公開的照片與真實心得。不要購買排名連結、洗評論或批量複製地區頁。
- 本地排名受到關聯性、距離與熱門程度影響；完善資料有助匹配，無法讓所有地區看到相同位置。[Google 本地排名](https://support.google.com/business/answer/7091?hl=zh-Hant)

## 量測與調整規則

- Search Console：搜尋類型 Web、國家台灣；分手機／桌面，比較最近 28 天與前 28 天。分開報告純 SUZUKI、地區詞、車款詞、顧問姓名詞；若已有一年資料再看季節性。

- 事件建議：`line_click`、`phone_click`、`consultation_success`。成功事件只在 API 確認持久收件後觸發；不傳姓名、電話、表單內容或可識別客戶的案件資料到分析工具。
- 若採 GA4，可在分析中觀察 Organic Search 工作階段與上述事件；LINE 後續對話、實際來電和試乘須由顧問另行確認，避免把所有點擊當成有效詢問。
- 有曝光但點擊少：查看查詢意圖及結果版面，調整 title／摘要與主文。內容未收錄：先查 URL Inspection、canonical、回應與內容品質。已有點擊但沒詢問：檢查手機諮詢流程與資訊是否足以支持決策。
- 90 天驗收工作產出：首頁定位調整、6 個車款頁、1 個到店頁、4 篇原創指南、量測基準與每月報表。成效另記收錄率、目標詞表現和有效諮詢；不能以完成頁數代替 SEO 成效。

# 測試清單與選跑規則

更新：2026-09-09。依業主要求精簡；不再每次更新網站都執行全部測試。以下為目前規則，歷史報告中的全套驗證不代表日常要求。

## 執行方式

| 修改範圍 | 檢查 |
|---|---|
| 文件 | `git diff --check` |
| 指南／FAQ 資料與內部連結 | `npx tsx --test tests/content.test.ts` |
| 車款價格關聯、canonical、sitemap 資料 | `npx tsx --test tests/seo.test.ts` |
| 優惠期間或判定 | `npx tsx --test tests/promotions.test.mjs` |
| 照片手勢邏輯 | `npx tsx --test tests/photo-gestures.test.ts` |
| SEO 頁面輸出／路由 | `npm run test:browser -- --project=http` |
| FAQ／指南互動 | `npm run test:browser -- guides-faq.spec.ts`，可加 `--grep` 選情境 |
| 諮詢入口／跨頁草稿／車款頁互動 | `npm run test:browser -- seo.spec.ts`，可加 `--grep` |
| 彈窗／貸款試算 | `npm run test:browser -- site.spec.ts --grep "loan"` 等受影響情境 |
| 元件／SEO／路由／樣式 | 若未跑包含建置的瀏覽器測試，執行 `npm run build` |
| 視覺修改 | 檢視受影響頁面的桌面與手機版面 |
| 依賴更新 | `npm audit`，依受影響功能選測試 |

`npm test` 為手動全套 7 項資料／邏輯測試；`npm run test:browser` 為手動核心 11 項（1 HTTP＋5 情境各跑桌面／手機）。只有大範圍修改或明確要求時才跑完整瀏覽器套件。瀏覽器指令已建置一次，不要對相同版本再建置。每次修改最後執行 `git diff --check`。

| 橫向滑動換一張照片 | 保留：只在手勢邏輯修改時跑 |

| 優惠無效日期不顯示 | 保留：屬優惠判定，非諮詢輸入驗證 |

## 瀏覽器核心清單（第二次精簡後）

| 保留 | 範圍 |
|---|---|
| HTTP SEO | 全站狀態、H1、canonical、標題、sitemap、404；只跑一次，不開瀏覽器 |
| 車款到諮詢 | 首頁 → SWIFT → 諮詢；草稿、車款預選、比較選取、LINE／電話連結 |
| 照片彈窗 | 開啟、換照片、載入圖片、Esc 逐層關閉與焦點返回 |

後五項各跑桌面／手機，共 11 項。每項只保留代表操作，沒有把原本整套步驟藏進少量測試。

- FAQ 保留基本搜尋／分類；刪除額外 SWIFT 問答跨頁動線。

不產生例行截圖；保留失敗 trace。未保留的細節若日後修改，以當次受影響功能的人工檢查處理，不自動恢復大型回歸套件。

## 隔離與範圍

測試伺服器仍清空 Blob、Discord、Sheets 與 GA4 設定；瀏覽器仍攔截諮詢 API，避免使用本機既有正式憑證。刪除的是測試，網站收件、通知、驗證、去重及分析實作未更動。不得以本機檢查推論正式收件或外部通知成功。
